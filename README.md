# 適切なケアマネジメント手法項目一覧表 (ケアプランＡＩ)

介護保険制度におけるケアマネジメントツール**「適切なケアマネジメント手法」**の全9テーマ（基本ケア、脳血管疾患Ⅰ・Ⅱ期、大腿骨頸部骨折Ⅰ・Ⅱ期、心疾患Ⅰ・Ⅱ期、認知症、誤嚥性肺炎の予防）のPDFデータを完全に統合し、PCおよびタブレット環境でスムーズに利用できるインタラクティブなWebアプリケーションです。

---

## 🌟 主な特徴

1. **ブランドロゴ配置**: ヘッダー最上部に「ケアプランＡＩ」ブランドロゴを配置。
2. **9シート（タブ）切替**: 「基本ケア」から「誤嚥性肺炎の予防」まで9つのテーマをワンタップでスムーズ切り替え。
3. **PDF概要表の完全再現**: PDFの2ページ目の項目一覧（基本方針・大項目・中項目・小項目・想定される支援内容）を忠実かつ見やすく固定再現。
4. **横スライド詳細表示**: 各「想定される支援内容」の項目ボタンを押すと、画面右側から詳細カード（支援の概要、アセスメント・モニタリング項目、相談専門職）がスライド表示。
5. **「閉じる」ボタン設置**: 一タップで元の一覧表にスムーズに戻れる設計。
6. **タブレット最適化**: タップしやすい大きなボタン領域（48px以上）と快適なレスポンシブデザイン。
7. **完全コストゼロ**: サーバー・データベース不要の静的Webアプリ（HTML/CSS/JS）。

---

## 🚀 完全無料でWeb公開する手順（おすすめ順）

本ツールは特別なサーバー処理が不要な静的HTMLアプリケーションですので、以下のサービスで**完全無料（0円）**で公開できます。

### 方法1: GitHub Pages を利用する（推奨）

1. 本プロジェクトのコードを GitHub のリポジトリにプッシュ（アップロード）します。
2. GitHubリポジトリの画面で **[Settings]** > **[Pages]** を開きます。
3. Build and deployment の Source で **`Deploy from a branch`** を選択し、Branch を **`main` / `/ (root)`** に設定して **[Save]** をクリックします。
4. 数分後、発行されたURL（`https://<ユーザー名>.github.io/<リポジトリ名>/`）から、誰でも閲覧・利用可能になります。

---

### 方法2: Vercel または Netlify で公開する

1. [Vercel](https://vercel.com) または [Netlify](https://www.netlify.com) にアクセスして無料アカウントを作成します。
2. ダッシュボードの Deploy 領域に、本プロジェクトフォルダ（`Appropriatecaremanagement`）をそのまま**ドラッグ＆ドロップ**します。
3. 数秒で世界中からアクセス可能なWeb公開URLが即座に発行されます。

---

## 💻 ローカル環境・タブレット単体での利用方法

Webに公開せずオフラインで利用したい場合は、本フォルダ内の `index.html` をPCやタブレットのブラウザ（Google Chrome, Safari, Microsoft Edgeなど）で直接ダブルクリックして開くだけで、インターネット接続がなくても完全に機能します。
